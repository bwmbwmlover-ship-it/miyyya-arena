# Source recovery status

**Important: this folder is not a verified export of the original ChatGPT Site at `miya-arena.bwmbwmlover.chatgpt.site`.** The original site's full source tree could not be extracted through its public URL in this environment. This standalone project is an independently reconstructed playable frontend based on the screenshots and accessible source files/notes.

Included: responsive setup page, 10 subjects, 5 game modes, two player names, selectable stylized car illustrations, difficulty and duration controls, keyboard/mouse answers, local question bank, timer, scoring, basic race progression, 3-round arena mode, modal help, language UI switching, generated sound cues, and local assets.

Not verified as identical to the original: exact original question count and wording, every vehicle/animation, original music tracks, every original button interaction, and any unshown gameplay screens or advanced mode rules. The local question bank is a starter set rather than a claim of 440 exact original geography questions.
